# Tidal Works: lower estuary survey, 1890–1911 — digitisation package

Released digitisation package for the Tidal Works collection (archive reference BWA/PH/0142).

## What is in this repository

- `plates/` — 30 archival plate scans, 600 dpi TIFF with LZW compression
- `metadata/catalogue.csv` — item-level catalogue records for every plate
- `metadata/iiif-manifest.json` — IIIF Presentation 3 manifest for the set
- `checksums.sha256` — SHA-256 checksums for all plate files
- `LICENSE.txt` — rights statement

## Provenance

The plates were digitised from the original negatives held in the archive's climate-controlled store. Each plate was captured at 600 dpi on a calibrated flatbed scanner; a colour target was captured at the start of each tray.

## Reuse
